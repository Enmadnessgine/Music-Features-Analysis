This is short documentary about functionality of ML/DS core

Interaction:
  From now on, every useful function you could take from class in DataModifying/models/ModelRegistry.py
  about functionality: class "ModelRegistry" has static method get() with params:
      "genre" - identifies subgenre
      "user_profile" - return statistics based on user profile

Data Science:
    I made multi-stage models with 4 macrogenre (vocal, energetic, calm, acoustic)
    and subgenre inside them. here variable from DataModifying/models/config.py to understand more:
      GROUPS = {
        'vocal' : ["pop", "reggae", "rap", 'hip-hop'],
        'energetic' : ["electronic", "rock"],
        'calm' : ["ambient", "classical"],
        'acoustic' : ["jazz", "folk"],
        }

  Furthermore, I log some features and clipped them (by 0.25 and 0.75 percentile).
  Due to specific of RandomForests (which i use the most), I refuse to make more preprocessing.


Machine Learning:
  PCA - some noise with "energy" and "loudness"
  model: RandomForest. It fits excellent and don't require scaling. Perfect model for easy classification,
         but need some experiments with boosting model in the future.
  mean accuracy: 0.83 (vocal macrogenre has the least appropriate accuracy 0.63 due to similarity of subclasses)


Future/Hypothesis:
  I believe It has a lot of potential to vectorise features and make "reliable tracks" from other users in DB.
  Although ML core fits perfectly, I would like to see Deep Learning model to make more complex analytics.
